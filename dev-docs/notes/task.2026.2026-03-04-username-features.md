## Use Case

As a team member, I would like to be able to generate filenames differentially per user by including {username} support in the filename template

Similarly, I'd like to be able to include the username in the output directories as well.

The "conversation turn" headings could integrate the preferred username, instead of "# User_2026-03-03_1959_51" it could be "
# djradon_2026-03-03_1959_51"
